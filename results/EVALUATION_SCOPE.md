# Evaluation resources

The frozen PSM-Bench component ledger reproduces all 14 reported systems using Scientific Mastery v4.3 and Huber aggregation. Final answers, original references and anonymous human judgments are separate files. No model generation or new judging was performed.

Exact text-to-component recomputation uses original source-support anchors, which are intentionally excluded. Frozen component aggregation and final score reproduction require no private corpus.

The public deterministic text scorer requires explicitly supplied full source-support records; public gold references alone do not reproduce the original component algorithm.

S20 scientific ratings are archived blinded assisted assessments; no local algorithm regenerates those expert ratings. The supplied code reproduces aggregation and Pro anchoring.

Bootstrap helpers record their RNG/percentile profile. Archived confidence intervals are retained separately; no claim is made that a different RNG reproduces historical final digits.

Perovskite-R1 original questions and author outputs are not redistributed; a required-local-input adapter is provided.

Model-generated final answers and original benchmark references are released; retrieval evidence packets, article passages and blind identity keys are excluded.
