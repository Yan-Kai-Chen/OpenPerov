# Public resources and retained corpus

OpenPerov distributes model adaptations, implementation code and evaluation resources. The source literature collection and its training/retrieval derivatives remain private.

The public evaluation files contain questions, their task context, original reference answers and criteria, selected final answers, anonymized human judgments and numerical score records. The training corpus, full article texts, Integrated Article Evidence Records, citation-context passages, topic summaries, retrieval documents, vector indexes and retrieved evidence packets are excluded. Benchmark inputs and reference/scoring files are separate.

The portable Pro path accepts evidence supplied by its user. The synthetic fixture illustrates the schema; it is not an experimental result or a subset of the private corpus. No command downloads the private corpus or silently uses it as a dependency.

The published component ledgers support exact recalculation of the paper's Scientific Mastery v4.3 aggregates. The original text-to-component scorer also uses source-support text, which belongs to the retained corpus. Its code is provided, and exact component recomputation requires the user to supply that support explicitly. A public reference answer alone is not a replacement for the original support field. See EVALUATION.md for the executable commands and protocol distinctions.

Model identities in final comparison tables are scientific result labels. Private blind mappings and evaluator identifiers are excluded. The Expert + AI reference condition denotes expert-determined and expert-checked scientific content with AI assistance in wording and organization. It is separate from the human assessment of 3,200 model answers.

No whole historical handoff archive is a public-release input. Files are selected individually, and the release manifest records their public hashes. Local preparation records, machine paths, credentials and remote-access details remain outside this repository.
